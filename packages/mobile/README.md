# trizum mobile

Capacitor wrappers for the trizum PWA, distributed through the App Store and Google Play.

- **Set up or run locally:** [Mobile development](./docs/development.md).
- **Change native lifecycle, plugins, or assets:** [Native wrapper](./docs/native-wrapper.md).
- **Run build or upload lanes:** [Fastlane](./docs/fastlane.md).
- **Edit store listings, screenshots, or privacy answers:** [Store metadata](./docs/store-metadata.md).
- **Change ads or purchases:** [Monetization](./docs/monetization.md).
- **Validate or release native builds:** [Releases and CI](./docs/releases.md).
- **Configure signing or CI credentials:** [Signing](./docs/signing.md).

Package commands live in [`package.json`](./package.json) and
[`vite.config.ts`](./vite.config.ts); run them from this directory with `vp run`.
Shared app UI lives in the [PWA package](../pwa/README.md).
