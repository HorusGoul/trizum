# Translation guidance

These rules apply to trizum locale catalogs.

- **Translate any locale:** read [terminology](./docs/terminology.md) and
  [formatting and tone](./docs/formatting-and-tone.md) for product meanings,
  Lingui placeholders, and brand names.
- **Translate Spanish:** also read [Spanish conventions](./docs/spanish.md).
- **Change source copy or extract messages:** follow [PWA conventions](../../../docs/agents/pwa.md).

Review existing translations for context; ask about unclear meanings before
translating. Verify placeholders, terminology, formatting, and tone after editing,
and test translations in context where possible.
